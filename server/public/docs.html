Embeddable video player

Just pass a TMDB ID. Works for movies and TV shows.

Quick embed
<iframe src="https://scrapers.moovie.fun/embed/movie/550" width="100%" height="500" frameborder="0" allowfullscreen allow="autoplay; encrypted-media"></iframe>

Embed

Embed a movie or TV player using a clean URL structure with optional query parameters.

Endpoints

GET
/embed/movie/{tmdbId}
Embed a movie player
GET
/embed/tv/{tmdbId}/{season}/{episode}
Embed a TV show player

Query parameters still work too: ?tmdb=550&type=movie

Parameters

Parameter Type Required Description
tmdb string Yes TMDB movie or TV show ID
type "movie" | "tv" No Content type. Auto-detected if using path URLs.
season number TV only Season number
episode number TV only Episode number

Optional parameters

Parameter Type Default Description
autoplay boolean true Set to 0 to disable autoplay

API

Use the search endpoint to get proxy URLs for programmatic use.

GET
/api/search?q={tmdbId}&type={movie|tv}&season={N}&episode={N}
Search for streams by TMDB ID
GET
/proxy?id={streamId}
Proxy a stream by ID (from search results)

Search parameters

Parameter Type Required Description
q string Yes TMDB ID (e.g. 550 for Fight Club)
type "movie" | "tv" No Content type (default: movie)
season number TV only Season number
episode number TV only Episode number

React
function MoovieEmbed({ tmdb, type, season, episode }) {
  var src = type === 'tv'
    ? 'https://scrapers.moovie.fun/embed/tv/' + tmdb + '/' + season + '/' + episode
    : 'https://scrapers.moovie.fun/embed/movie/' + tmdb;
  return (
    <iframe src={src} width="100%" height="500"
      frameBorder="0" allowFullScreen
      allow="autoplay; encrypted-media" />
  );
}
Programmatic
fetch('https://scrapers.moovie.fun/api/search?q=550&type=movie')
  .then(r => r.json())
  .then(data => {
    var stream = data.results[0].streams[0];
    var hls = new Hls();
    hls.loadSource(stream.proxyUrl);
    hls.attachMedia(document.getElementById('video'));
  });
